DoubleLoopRBDOAlgorithm¶

class otrobopt.DoubleLoopRBDOAlgorithm(*args)¶

Double-loop reliability-based design optimization.

This class is experimental and may change in future releases.

The algorithm solves the reliability-based design optimization problem

where is a scalar classical function and the chance constraint is given by a JointChanceMeasure. The distribution parameter is kept fixed. An outer deterministic optimization calls an inner reliability analysis in the standard normal space.

Two inner formulations are available through setMethod():

  • DoubleLoopRBDOAlgorithm.RIA minimizes the distance to the limit state. The outer constraint is , where the signed reliability index is negative when the origin of the standard space belongs to the failure domain.

  • DoubleLoopRBDOAlgorithm.PMA minimizes the limit state on the sphere of radius . The outer constraint is the performance measure at the target point.

The target index is , where is the safe-event probability. For a Greater operator the safe event is and . For a Less operator the safe event is the complementary event and . Both formulations therefore require .

A vector limit state is handled with the setJointChanceTreatment() option. EXACT uses the exact joint event: the intersection for a Greater operator and the complementary union for a Less operator. BONFERRONI replaces the joint event by component events with the conservative target ; it is less tight but avoids a nonsmooth scalarization. The treatment is always explicit and is reported by getJointChanceTreatment().

Notes

The inner optimization is performed in the standard normal space. The standard-space limit state is built from the inverse isoprobabilistic transformation of the distribution. The origin of the standard space is the median point of the distribution.

The algorithm requires the limit-state function to expose a parameter gradient when a gradient-based inner solver is used. The default Cobyla inner solver does not require it.

The default inner solver tolerances can be changed with the ResourceMap keys DoubleLoopRBDOAlgorithm-DefaultInnerMaximumIterationNumber, DoubleLoopRBDOAlgorithm-DefaultInnerMaximumConstraintError and DoubleLoopRBDOAlgorithm-DefaultInnerMaximumAbsoluteError.

The result is available through the inherited getResult method. The reliability analysis at the solution is reported by getReliabilityIndex(), getPerformanceMeasure(), getStandardSpaceDesignPoint(), getPhysicalSpaceDesignPoint() and getApproximateProbability().

Examples

>>> import openturns as ot
>>> import otrobopt
>>> limitState = ot.ParametricFunction(
...     ot.SymbolicFunction(["x", "theta"], ["theta - x"]), [1], [0.0]
... )
>>> measure = otrobopt.JointChanceMeasure(
...     limitState, ot.Normal(), ot.GreaterOrEqual(), 0.9
... )
>>> problem = otrobopt.RBDOProblem(
...     ot.SymbolicFunction(["x"], ["x^2"]), measure
... )
>>> algo = otrobopt.DoubleLoopRBDOAlgorithm(
...     problem, ot.Cobyla()
... )
>>> algo.setMethod(otrobopt.DoubleLoopRBDOAlgorithm.PMA)
>>> algo.run()
>>> result = algo.getResult()

setProgressCallback(*args)¶

Set up a progress callback.

Can be used to programmatically report the progress of an optimization.

Parameters:
callbackcallable

Takes a float as argument as percentage of progress.

Examples

>>> import sys
>>> import openturns as ot
>>> rosenbrock = ot.SymbolicFunction(['x1', 'x2'], ['(1-x1)^2+100*(x2-x1^2)^2'])
>>> problem = ot.OptimizationProblem(rosenbrock)
>>> solver = ot.OptimizationAlgorithm(problem)
>>> solver.setStartingPoint([0, 0])
>>> solver.setMaximumResidualError(1.e-3)
>>> solver.setMaximumCallsNumber(10000)
>>> def report_progress(progress):
...     sys.stderr.write('-- progress=' + str(progress) + '%\n')
>>> solver.setProgressCallback(report_progress)
>>> solver.run()
