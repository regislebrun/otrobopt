CanonicalizationOptions¶

class otrobopt.CanonicalizationOptions(*args)¶

Options of the robust problem canonicalizer.

This class is experimental and may change in future releases.

The worst-case policy selects both the reference distribution and the treatment of the worst-case optimization domain:

  • AUTO: use the explicit reference distribution when it is set, otherwise the standard fast path when it is available, otherwise the standard normal distribution. For a worst-case measure, an explicit domain is required unless the standard fast path is used or the reference has a bounded range.

  • STANDARD: require the standard fast path.

  • NORMAL: force the standard normal reference.

  • USER_REFERENCE: require reference.

  • USER_DOMAIN: use the automatic reference policy and require worstCaseDomain.

Attributes:
referenceDistribution

Reference distribution, empty for the automatic policy.

parameterBoundsInterval

Bounds on the active distribution parameter, empty for no bounds. A full-dimensional interval is also accepted and filtered to the active coordinates.

parameterStartPoint

Initial active distribution parameter, empty for the current parameter. A full-dimensional point is also accepted and filtered to the active coordinates.

activeParameterIndices

Active parameter indices in the full distribution parameter. When it is not set, the default policy of ParametricDistributionTransformation is used: the trailing dependence or copula block is inactive.

optimizeParameterbool

Whether the distribution parameter is part of the decision vector. Default is True. When the active parameter is empty, the parameter is frozen and the decision vector is reduced to the design variables.

worstCasePolicyint

Worst-case policy. Default is CanonicalizationOptions.AUTO.

worstCaseDomainInterval

Worst-case optimization domain in the reference space, empty for the range of the reference distribution.

The attributes can also be set with the ``setReference``,
``setParameterBounds``, ``setParameterStart``, ``setActiveParameter``,
``setOptimizeParameter``, ``setWorstCasePolicy`` and
``setWorstCaseDomain`` methods, which accept the usual Python arguments. Use
``setReference`` to select explicitly the default ``Uniform(-1, 1)``
distribution as reference.
