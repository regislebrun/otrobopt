ProbabilityEstimator¶

class otrobopt.ProbabilityEstimator(*args)¶

Handle to an estimator of the probability of a system event.

The handle owns its estimator by a shared pointer, so that a chance measure can be copied and persisted without slicing the concrete estimator. The concrete estimators derive from ProbabilityEstimatorImplementation and are accepted wherever a ProbabilityEstimator is expected.

The event is a Boolean predicate of the indicators of limit-state components. With the -th component at the design point for the realization of the distribution , the indicator is and the event is

The predicate is a openturns.Function with inputs, one output and no parameter; it must return 0 or 1. The limit state is a parametric openturns.Function whose parameter is . The estimator is stateless: every call receives the predicate, the limit state, the distribution and the design point.

The probability is returned before the probit transform applied by the chance measure. getEstimationError() returns NaN when the estimator has no error estimate for the requested call.
