QuadratureEstimator¶

class otrobopt.QuadratureEstimator(*args)¶

Deterministic quadrature estimator of a system-event probability.

For a continuous distribution of density , the probability is the Lebesgue integral

The density threshold only truncates the tails of this continuous integrand.

For a discrete distribution, the probability is the exact sum over the support,

and no threshold is applied: dropping a low-probability atom would change the probability instead of truncating a density tail.

The estimator is deterministic and has no geometry. Its getEstimationError() is NaN because the integration algorithm does not return a quadrature gap.

Parameters:
algorithmopenturns.IntegrationAlgorithm

Integration algorithm used for the continuous branch. It defaults to an iterated Gauss-Kronrod quadrature.

Examples

>>> import openturns as ot
>>> import otrobopt
>>> f = ot.ParametricFunction(
...     ot.SymbolicFunction(["x", "theta"], ["x - theta"]), [1], [0.0]
... )
>>> predicate = ot.SymbolicFunction(["y0"], ["y0"])
>>> estimator = otrobopt.QuadratureEstimator()
>>> abs(estimator.getSafeProbability(predicate, f, ot.Normal(), [0.0]) - 0.5) < 1e-10
