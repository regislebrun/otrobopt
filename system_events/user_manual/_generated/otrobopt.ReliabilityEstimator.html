ReliabilityEstimator¶

class otrobopt.ReliabilityEstimator(*args)¶

First-order estimator of the probability of a Boolean system event.

The estimator analyses each of the components of the limit-state function by FORM, optionally restarted to collect several design points (MultiFORM). The failure event of component is linearized in the standard space as , where is the unit normal obtained from the design point and is its signed distance to the origin. The sign carries the orientation, so that a component safe event with a probability larger than one half is represented without clamping.

The system event is the Boolean predicate applied to the linearized component indicators. Its probability is combined exactly over the atoms of the linearized half-spaces; an atom probability is the orthant probability of the standard normal law with correlation matrix . The exact combination is attempted only when does not exceed getMaximumCombinationNumber(). Above that bound the estimator returns the midpoint of the first-order bounds obtained from the component marginals, and reports their half-width as the estimation error: the result is then an explicitly bounded estimate, never a silently truncated exact sum.

The analytical combination requires a normal standard space, that is a distribution whose standard distribution is the standard normal law. For any other distribution the system algorithm must be SIMULATION, which samples the distribution, applies the predicate to the component indicators and reports the binomial standard error.

Parameters:
componentAlgorithmstr

FORM or MULTIFORM. MULTIFORM restarts the nearest-point search to collect the competing design points of a component.

Examples

>>> import openturns as ot
>>> import otrobopt
>>> limitState = ot.ParametricFunction(
...     ot.SymbolicFunction(["x", "theta"], ["x - theta"]), [1], [0.0]
... )
>>> predicate = ot.SymbolicFunction(["y0"], ["y0"])
>>> estimator = otrobopt.ReliabilityEstimator("FORM", "ANALYTICAL")
>>> probability = estimator.getSafeProbability(
...     predicate, limitState, ot.Normal(), [1.0]
... )
>>> abs(probability - ot.Normal().computeCDF(1.0)) < 1e-6
