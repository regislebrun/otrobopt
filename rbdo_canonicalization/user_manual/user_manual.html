User manual¶

The goal is to formulate and solve robust optimization problem.

A robust optimization problem consists of a parametric objective objective and/or a parametric inequality constraint where is a design variable and a parameter.

The problem is made robust by:

  • modelling the parameter by the the random vector with given distribution .

  • choosing measure functions and for the objective and constraint functions.

The definition of the measure functions is associated to the concept of MeasureEvaluation.

A measure evaluation can be used through MeasureFunction to expose generic function services.

A robust optimization problem can be defined with RobustOptimizationProblem, and then solved using a RobustOptimizationAlgorithm.

Note that this measure evaluation can be discretized over so as to define a deterministic optimization problem using MeasureFactory.

Solve a reliability-based design optimization problem¶

The specialized algorithms accept an RBDOProblem and read the target probability and the comparison operator from its joint chance measure.

DoubleLoopRBDOAlgorithm(*args)

Double-loop reliability-based design optimization.

SORARobustOptimizationAlgorithm(*args)

Sequential optimization and reliability assessment.

SampleAverageApproximationAlgorithm(*args)

Sample-average approximation for reliability-based design optimization.

DoubleLoopRBDOAlgorithm supports RIA and PMA and accepts problems where the design and random dimensions differ. SORARobustOptimizationAlgorithm uses the physical shift and therefore requires equal design and random dimensions; it rejects a mismatched problem with an explicit error. SampleAverageApproximationAlgorithm accepts any target probability and is not restricted to a positive reliability index.
