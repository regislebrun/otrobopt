RobustOptimizationProblemCanonicalizer¶

class otrobopt.RobustOptimizationProblemCanonicalizer(*args)¶

Canonicalize a robust optimization problem over a fixed reference distribution.

This class is experimental and may change in future releases.

The canonical decision vector is where is the design vector and is the active parameter of the distribution . The measure distribution becomes a fixed reference distribution and the parametric functions are rebuilt as

where transports to .

The active parameter is selected by options.activeParameter when it is set, otherwise by the default policy of ParametricDistributionTransformation: all parameters are active except the trailing dependence or copula block. The parameter bounds and the starting point are expressed in the active coordinates, with the full parameter vector accepted as a compatibility fallback.

When options.optimizeParameter is false, or when the active parameter is empty, the distribution parameter is frozen at options.parameterStart and the canonical decision vector is only.

Examples

>>> import openturns as ot
>>> import otrobopt
>>> thetaDist = ot.Normal(2.0, 0.1)
>>> fBase = ot.SymbolicFunction(['x', 'theta'], ['x * theta'])
>>> f = ot.ParametricFunction(fBase, [1], [1.0])
>>> measure = otrobopt.VarianceMeasure(f, thetaDist)
>>> problem = otrobopt.RobustOptimizationProblem(measure, ot.Function())
>>> canonicalizer = otrobopt.RobustOptimizationProblemCanonicalizer(problem)
>>> canonicalizer.getCanonicalProblem().getDimension()
3
