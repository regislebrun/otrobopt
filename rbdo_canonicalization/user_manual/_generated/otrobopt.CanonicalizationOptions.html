CanonicalizationOptions¶

class otrobopt.CanonicalizationOptions(*args)¶

Options of the robust problem canonicalizer.

This class is experimental and may change in future releases.

The worst-case policy selects both the reference distribution and the treatment of the worst-case optimization domain:

  • AUTO: use the explicit reference distribution when it is set, otherwise the standard fast path when it is available, otherwise the standard normal distribution. For a worst-case measure, an explicit domain is required unless the standard fast path is used or the reference has a bounded range.

  • STANDARD: require the standard fast path.

  • NORMAL: force the standard normal reference.

  • USER_REFERENCE: require reference.

  • USER_DOMAIN: use the automatic reference policy and require worstCaseDomain.

Notes

The options are set with the accessors of the class:

  • setReference: reference distribution, empty for the automatic policy. It also selects explicitly the default Uniform(-1, 1) distribution as reference.

  • setParameterBounds: bounds on the active distribution parameter, empty for no bounds. A full-dimensional interval is also accepted and filtered to the active coordinates.

  • setParameterStart: initial distribution parameter, empty for the current parameter. When the parameter is optimized, the point is expressed in active coordinates; a full-dimensional point is also accepted and only its active coordinates are used. When the parameter is frozen, a full-dimensional point sets the whole distribution parameter, so that the frozen distribution is exactly the requested one.

  • setActiveParameter: active parameter indices in the full distribution parameter. When it is not set, the default policy of ParametricDistributionTransformation is used: the trailing dependence or copula block is inactive.

  • setOptimizeParameter: whether the distribution parameter is part of the decision vector. Default is True. When the active parameter is empty, the parameter is frozen and the decision vector is reduced to the design variables.

  • setWorstCasePolicy: worst-case policy, CanonicalizationOptions.AUTO by default.

  • setWorstCaseDomain: worst-case optimization domain in the reference space, empty for the range of the reference distribution. When the distribution parameter is frozen, an empty option domain preserves the domain stored by the measure instead; an explicit option domain takes precedence over it. When the parameter is optimized, a domain stored by a worst-case measure is rejected, because it is expressed in the original distribution coordinates and cannot be transported in general.

Examples

>>> import openturns as ot
>>> import otrobopt
>>> options = otrobopt.CanonicalizationOptions()
>>> options.setOptimizeParameter(False)
>>> options.setParameterStart([2.0, 0.5])
