SORARobustOptimizationAlgorithm¶

class otrobopt.SORARobustOptimizationAlgorithm(*args)¶

Sequential optimization and reliability assessment.

This class is experimental and may change in future releases.

The algorithm solves the reliability-based design optimization problem

where is a scalar classical function and the chance constraint is given by a JointChanceMeasure. The distribution parameter is kept fixed. The joint chance constraint is handled by sequential optimization and reliability assessment (SORA): a sequence of deterministic optimizations with shifted constraints alternates with a performance-measure analysis (PMA) in the standard normal space.

A vector limit state is handled with the setJointChanceTreatment() option:

  • SORARobustOptimizationAlgorithm.EXACT uses one scalarized system limit state for the PMA and maintains one shift. This is a FORM approximation of the joint event, not an exact system reliability calculation.

  • SORARobustOptimizationAlgorithm.BONFERRONI replaces the joint event by component events with the conservative target . Each component has its own PMA and its own shift.

Notes

The PMA is performed in the standard normal space. The standard-space limit state is built from the inverse isoprobabilistic transformation of the distribution. The origin of the standard space is the median point of the distribution.

The algorithm requires the limit-state function to expose a gradient when a gradient-based deterministic or inner solver is used. The default Cobyla solvers do not require it.

The outer loop uses the inherited controls setMaximumIterationNumber, setMaximumAbsoluteError and setMaximumRelativeError. The result status is SUCCESS when both the design and the shift converge, INTERRUPTION when the stop callback interrupts the loop, and FAILURE when the maximum number of iterations is reached first. The status message reports the selected joint chance treatment.

The default inner solver tolerances can be changed with the ResourceMap keys SORARobustOptimizationAlgorithm-DefaultInnerMaximumIterationNumber, SORARobustOptimizationAlgorithm-DefaultInnerMaximumConstraintError and SORARobustOptimizationAlgorithm-DefaultInnerMaximumAbsoluteError.

The result is available through the inherited getResult method. The reliability analysis at the solution is reported by getReliabilityIndex(), getPerformanceMeasure(), getShift(), getStandardSpaceDesignPoint(), getPhysicalSpaceDesignPoint() and getApproximateProbability().

Examples

>>> import openturns as ot
>>> import otrobopt
>>> limitState = ot.ParametricFunction(
...     ot.SymbolicFunction(["x", "theta"], ["theta - x"]), [1], [0.0]
... )
>>> measure = otrobopt.JointChanceMeasure(
...     limitState, ot.Normal(), ot.GreaterOrEqual(), 0.9
... )
>>> problem = otrobopt.RBDOProblem(
...     ot.SymbolicFunction(["x"], ["x^2"]), measure
... )
>>> algo = otrobopt.SORARobustOptimizationAlgorithm(
...     problem, ot.Cobyla()
... )
>>> algo.run()
>>> result = algo.getResult()

Parameters:

Examples

>>> import sys
>>> import openturns as ot
>>> rosenbrock = ot.SymbolicFunction(['x1', 'x2'], ['(1-x1)^2+100*(x2-x1^2)^2'])
>>> problem = ot.OptimizationProblem(rosenbrock)
>>> solver = ot.OptimizationAlgorithm(problem)
>>> solver.setStartingPoint([0, 0])
>>> solver.setMaximumResidualError(1.e-3)
>>> solver.setMaximumCallsNumber(10000)
>>> def report_progress(progress):
...     sys.stderr.write('-- progress=' + str(progress) + '%\n')
>>> solver.setProgressCallback(report_progress)
>>> solver.run()
