SampleAverageApproximationAlgorithm¶

class otrobopt.SampleAverageApproximationAlgorithm(*args)¶

Sample-average approximation for reliability-based design optimization.

This class is experimental and may change in future releases.

The algorithm replaces the chance constraint of an RBDOProblem by its empirical counterpart on a fixed calibration sample :

where is the safe event and is its target probability. For a Greater operator the safe event is and . For a Less operator it is the complementary event and . The empirical probability is used exactly, without a smooth surrogate; the resulting constraint is a step function and is solved by a derivative-free solver such as Cobyla.

After the optimization the safe probability is estimated again on an independent validation sample, and a Wilson 95% confidence interval is reported. The calibration and validation samples are available through getSample() and getValidationSample(); a user-supplied sample can be passed with setSample() or setValidationSample() and takes precedence over the corresponding size.

Notes

The distribution parameter is kept fixed. The algorithm accepts any target probability in , including targets for which the reliability index is not defined.

The calibration sample is generated at the beginning of run() and is kept fixed during the outer optimization. The validation sample is generated after the optimization. Both are drawn from the distribution of the joint chance measure with the global random generator. Set the seed before run() for reproducibility, or provide explicit samples.

The Wilson interval is a binomial confidence interval for the validation estimate. It quantifies the sampling error of the validation, not the bias of the calibration sample or the quality of the deterministic solver.

Examples

>>> import openturns as ot
>>> import otrobopt
>>> limitState = ot.ParametricFunction(
...     ot.SymbolicFunction(["x", "theta"], ["theta - x"]), [1], [0.0]
... )
>>> measure = otrobopt.JointChanceMeasure(
...     limitState, ot.Normal(), ot.GreaterOrEqual(), 0.9
... )
>>> problem = otrobopt.RBDOProblem(
...     ot.SymbolicFunction(["x"], ["x^2"]), measure
... )
>>> algo = otrobopt.SampleAverageApproximationAlgorithm(
...     problem, ot.Cobyla(), 1000
... )
>>> algo.setValidationSampleSize(10000)
>>> algo.run()
>>> result = algo.getResult()
>>> probability = algo.getSafeProbability()

>>> import sys
>>> import openturns as ot
>>> rosenbrock = ot.SymbolicFunction(['x1', 'x2'], ['(1-x1)^2+100*(x2-x1^2)^2'])

>>> solver.setMaximumResidualError(1.e-3)
>>> solver.setMaximumCallsNumber(10000)

...     sys.stderr.write('-- progress=' + str(progress) + '%\n')
>>> solver.setProgressCallback(report_progress)
>>> solver.run()
