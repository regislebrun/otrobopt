RBDOProblem¶

class otrobopt.RBDOProblem(*args)¶

Reliability-based design optimization problem.

This class is experimental and may change in future releases.

The problem couples a scalar classical objective with one joint chance constraint

or the variant defined by the comparison operator of the measure. The deterministic bounds, inequality constraints and equality constraints use the usual OptimizationProblem protocol.

Available constructors:

RBDOProblem(objective, jointChanceMeasure)

Parameters:
objectiveFunction

Scalar objective function . Its input dimension defines the design dimension.

jointChanceMeasureJointChanceMeasure

Joint chance constraint. Its limit-state function must have the same input dimension as the objective and its distribution dimension must match the limit-state function parameter dimension.

Notes

The joint chance measure returns the probit-transformed reliability index , not the probability itself. The target probability is available through getTargetProbability() and the comparison operator through getComparisonOperator().

The distribution parameter is frozen by default in the canonical problems returned by getCanonicalProblem() and getCanonicalJointChanceMeasure(). Use the overloads that accept CanonicalizationOptions to optimize the active parameter through the canonical decision vector .

Examples

>>> import openturns as ot
>>> import otrobopt
>>> limitState = ot.ParametricFunction(
...     ot.SymbolicFunction(["x", "theta"], ["theta - x"]), [1], [0.0]
... )
>>> measure = otrobopt.JointChanceMeasure(
...     limitState, ot.Normal(), ot.GreaterOrEqual(), 0.9
... )
>>> problem = otrobopt.RBDOProblem(
...     ot.SymbolicFunction(["x"], ["x^2"]), measure
... )
>>> problem.getTargetProbability()
0.9

Default canonicalization options of the specialized problem.

The distribution parameter is frozen by default. Use the overloads of getCanonicalizer(), getCanonicalProblem(), getCanonicalJointChanceMeasure(), getCanonicalDeterministicConstraint() and getCanonicalStartingPoint() that accept CanonicalizationOptions to optimize the active parameter.
